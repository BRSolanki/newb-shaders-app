### **2. Generate a Keystore (One-Time Setup)**

To build a **Release APK** (signed, installable, updateable), you need a signing key.

1.  **Open your terminal** (VS Code or CMD) inside the `android/app` folder.
2.  Run this command (replace `my-release-key` with a name you like):
    ```bash
    keytool -genkey -v -keystore newbshader.keystore -alias my-key-alias -keyalg RSA -keysize 2048 -validity 10000
